# RNN
* `循环神经网络，Recurrent Neural Network`
* 是一种专为处理`序列`数据设计的深度学习模型
* 其核心特点是通过 “`循环`” 结构保留机制`保留历史信息`，`模拟人类处理时序信息时的 “记忆” 能力`

### 序列中已观测到的上下文长度

* `“n” 可以理解为序列中已观测到的上下文长度，这确实是 RNN（以及所有序列模型）处理翻译或语言生成时的核心逻辑 ——随着输入序列长度 n 的增加，模型对后续内容的预测会更精准，就像输入法根据已输入的字符（n 越长）给出更贴切的联想词。`

具体来说，RNN 中 “n” 的作用机制：
1.` n 是 “已有的上下文信息”`
RNN 的核心是 “循环”：每一步输入一个 token（如单词、字符），并结合前一步的 “隐藏状态”（存储了前 n-1 个 token 的信息），更新出当前的隐藏状态（包含前 n 个 token 的信息）。
例如翻译时，输入 “ap”（n=2），隐藏状态会记录 “a” 和 “p” 的关联；输入 “app”（n=3），隐藏状态会叠加 “p” 的信息，此时模型更易推断出 “apple”（因为 “app” 比 “ap” 包含更明确的上下文）。
2. `n 越长，歧义性越低`
语言中存在大量歧义（如 “bank” 可指 “银行” 或 “河岸”），但随着 n 增大（上下文变长），歧义会被消解。
当 n=1（仅输入 “b”），模型几乎无法确定后续是 “bank”“book” 还是 “ball”；
当 n=4（输入 “go to the b”），结合 “go to the” 的语境，模型更可能联想出 “bank”（银行）而非 “bank”（河岸）。
这和输入法的逻辑完全一致：输入的字符越多（n 越大），联想越聚焦。

3. `RNN 对 n 的依赖与局限`
RNN 的 “隐藏状态” 本质是对前 n 个 token 的压缩编码，但它有一个关键缺陷：n 不能无限增大。
当 n 过大（如长句子），早期 token 的信息会在循环更新中逐渐衰减（梯度消失问题），导致模型对 “遥远的上下文” 记忆模糊。
例如输入超长句子 “... 昨天买的那个红色的、用来装书的、在超市三楼打折的...（中间 n=100 个词）... 它”，RNN 可能无法准确记住 “它” 指代的是 “红色的袋子” 还是 “书”。

## RNN的缺点
* `梯度消失`,原始 RNN 存在严重的梯度消失（Gradient Vanishing）问题，这也是其在处理长序列时性能受限的核心原因之一

* 一、梯度消失的产生原理
* 在神经网络训练中，模型通过`反向传播`（Backpropagation）计算损失对权重的梯度，进而更新参数。对于 RNN，由于其循环结构，梯度需要沿着时间步反向传递（即 “随时间反向传播”，Backpropagation Through Time, BPTT），这会导致梯度表达式中出现 “连乘项”，最终`引发梯度消失或爆炸`。

#### 梯度消失的例子

* 在 “小明昨天买了苹果，他今天吃了____” 这个例子中，原始 RNN 对 `“苹果”` 和 `“吃了”` 的关联能力差异，本质上是梯度随时间衰减速度导致的 —— `距离越远的信息，梯度消失越严重，关联能力越弱`。具体可以拆分为三个时间步来理解：

1. 序列的时间步拆分（简化版）
假设句子按以下时间步输入模型（每个词为一个时间步）：
[小明, 昨天, 买了, 苹果, ，, 他, 今天, 吃了, _]
其中，“苹果” 在时间步 4，“吃了” 在时间步 8，需要预测的空格在时间步 9。

2. 原始 RNN 对 “吃了” 的关联：短期依赖，梯度衰减少
当模型预测空格（时间步 9）时，需要关联 “吃了”（时间步 8）：

两者仅相差 1 个时间步，反向传播的梯度只需经过 1 次权重矩阵和激活函数导数的乘法。
即使使用 tanh 激活函数（导数≤1），梯度衰减也很小（例如从时间步 9 传到 8，梯度保留率可能在 80% 以上）。
因此，模型能轻易学到 “吃了” 与空格的关联（如 “吃了” 后面通常接食物）。

3. 原始 RNN 对 “苹果” 的关联：
长期依赖，梯度几乎消失而 “苹果”（时间步 4）与空格（时间步 9）相差 5 个时间步，梯度需要从时间步 9 反向传播 5 次才能到达时间步 4：
每次传播都要乘以激活函数的导数（如 tanh 导数≈0.5）和权重矩阵的影响，`经过 5 次连乘后`，梯度可能`衰减至初始值的 \(0.5^5 = 3.125\%\) 以下`。当梯度接近 0 时，模型无法通过反向传播更新与 “苹果” 相关的权重，导致 “苹果” 的信息无法传递到后期。因此，模型可能无法将 “吃了” 与 “苹果” 关联，只能凭 “吃了” 的短期上下文猜测（如填 “东西”“食物”，而非 “苹果”）。

### RNN的另一个缺点 无法高效并行计算
* 为什么 RNN 无法并行？
* RNN 的`循环特性`决定了其计算`必须按时间步顺序`执行，无法像 CNN 或 Transformer 那样对输入序列进行并行处理。具体来说：

在 RNN 中，`每个时间步的隐藏状态 \(h_t\) 依赖于前一个时间步的隐藏状`态 \(h_{t-1}\)：\(h_t = f(x_t, h_{t-1})\)

这意味着：`必须先计算完 \(h_1\) 才能计算 \(h_2\)，计算完 \(h_2\) 才能计算 \(h_3\)`，以此类推。整个序列的计算就像一条 “链条”，`每个环节都依赖前一个环节，无法同时计算多个时间步的隐藏状态。`

* 与并行计算友好的模型对比:
CNN：`卷积操作可以同时对图像的不同区域并行计算`，无论输入图像多大，`卷积核的计算都是并行的`。
Transformer：自注意力机制通过`矩阵运算`直接计算`所有 token 之间的关联`，整个序列的所有位置可以同时处理，完全并行。
